# ДронПрокат - вебплатформа оренди безпілотних апаратів

Навчальний прототип до курсу «Проєктування інформаційних систем», тема №46.
Виконала: Дзюбенко Дарина, ІК-32.

## Як відкрити готовий сайт (без встановлення)

Відкрийте файл `dist/index.html` у браузері - подвійним кліком.
Інтернет потрібен лише для шрифтів; без нього сайт працює зі стандартним шрифтом.

## Як запустити з вихідного коду

Потрібен Node.js 20 або новіший

```
npm install
npm run dev        # режим розробки, відкриється http://localhost:5173
npm run build      # збірка готового сайту в папку dist
npm run preview
```

## Як користуватись демо

Вгорі праворуч є перемикач «Увійти як». Ролі збігаються з діаграмою прецедентів КП1:

| Роль | Користувач | Що показати |
| --- | --- | --- |
| Гість | - | каталог, фільтри, картка комплекту, розрахунок вартості, пункти видачі |
| Орендар | Ірина Коваленко | бронювання → оплата → договір, мої оренди, підтвердження акта, спір, відгук, посвідчення |
| Власник техніки | Олег Савчук | мої комплекти, ресурс до ТО, блокування дат, нарахування й виплати, завантаження, новий комплект |
| Оператор-виконавець | Максим Гнатюк | прийняти або відхилити замовлення, розклад |
| Працівник пункту | Світлана Мельник | видача і повернення, акт з перевіркою кожної позиції |
| Адміністратор | Андрій Бондар | модерація, спори з порівнянням актів, тарифи й коефіцієнти, допуски, виплати, звіти |

Усі дії зберігаються в браузері (localStorage). Скинути демо: Адміністратор → Звіти → «Скинути демо».

## Структура

```
src/
  main.jsx            точка входу
  App.jsx             маршрутизація (#/...) і права доступу за ролями
  store.jsx           стан застосунку і всі дії (бронювання, акти, спори, модерація…)
  utils.js            дати, розрахунок вартості за тарифом і коефіцієнтами, перевірка доступності
  styles.css          стилі
  data/mock.js        демо-дані (відповідають сутностям ER-діаграми КП1)
  components/         шапка, кнопки, бейджі, модальні вікна, степер
  pages/              Catalog, KitPage, Checkout, Renter, Owner, KitEditor,
                      Operator, Desk, Act, Admin, Points, Login
```

## Перенесення екранів у Figma

Відкрийте сайт, встановіть у Figma плагін html.to.design і імпортуйте сторінку
(за адресою сайту або через розширення браузера). Екрани стануть редагованими шарами Figma.

## КП3: компонентно-орієнтований підхід

Адміністратор → «Реєстри»: 16 реєстрів даних (довідники, техніка, оренда, фінанси, користувачі),
зібраних з одних і тих самих компонентів. Адміністратор → «UI Kit»: бібліотека компонентів.

```
src/data/registry.js                  опис полів кожного реєстру (з нього будуються таблиця і форма)
src/pages/Registry.jsx                одна сторінка для всіх реєстрів
src/pages/UiKit.jsx                   бібліотека компонентів
src/components/PageHeader.jsx         заголовок сторінки з кнопками дій
src/components/SearchInput.jsx        поле пошуку
src/components/Pagination.jsx         перемикач сторінок
src/components/registry/DataTable.jsx      таблиця: пошук, сортування, сторінки, дії, CSV
src/components/registry/RecordForm.jsx     форма запису з автоматичною перевіркою полів
src/components/registry/CellValue.jsx      показ значення за типом поля
src/components/registry/ConfirmDialog.jsx  підтвердження видалення
src/components/registry/RegistrySidebar.jsx бічне меню реєстрів
```

## КП4: успадкування шаблонів, переходи й анімації

Усі сторінки побудовано на ієрархії шаблонів (src/components/templates):

```
BaseTemplate        шапка, область вмісту з анімацією переходу, підвал, повідомлення, вікно зворотного зв'язку
└ PageTemplate      + хлібні крихти, посилання назад, заголовок з кнопками дій
  ├ CabinetTemplate + вкладки        (Мої оренди, Моя техніка, Керування, Мої замовлення, Видача і повернення, Пункти видачі)
  ├ RegistryTemplate + бічне меню    (16 реєстрів)
  ├ FormTemplate    + кроки процесу  (Оформлення оренди, Новий комплект, Акти)
  └ DetailTemplate                   (Картка комплекту)
```

Нове: src/components/Breadcrumbs.jsx (хлібні крихти), src/components/FeedbackDialog.jsx (вікно після
оформлення оренди та відправки комплекту на модерацію), анімації в кінці styles.css: перехід між сторінками,
зміна вкладок і кроків, поява вікон, підсвічування доданого чи зміненого рядка, плавне видалення рядка,
стрілки сортування. Якщо в системі ввімкнено зменшення руху, анімації вимикаються.
